# 分心洞察（Focus Insight）

## 一、作品简介

**分心洞察**是一款运行在小米 Vela 手表上的专注守护快应用：开始专注后，利用手表**加速度计**实时监测手腕运动，一旦检测到分心动作（抬腕看表、大幅度活动等）立即**震动提醒**把你拉回状态；专注结束后自动生成分心明细台账与 AI 分析报告，让你看清"我到底在什么时候、因为什么走神"。

核心亮点：

- **传感器实时分心检测**：订阅 `@system.sensor` 加速度计数据，运动强度超阈值判定为分心，检测窗口+冷却期防止误报连震
- **双模式**：正常模式 / 高效模式（高效模式提醒更严格）
- **分心台账**：记录每次分心的发生时间与持续情况，可滚动查看（`pages/detail`）
- **AI 分析报告**：汇总专注时长、分心次数、久坐情况，生成建议（`pages/report`）
- **久坐强提醒**：连续 60 分钟完全无运动时触发长震动
- **优雅降级**：模拟器等无传感器环境自动切换模拟数据，界面显示 `[模拟传感器]` 标签，功能演示不受影响

## 二、选题方向

**手表应用创新**。

选择理由：专注力管理是学生与职场人的高频真实需求，但手机端番茄钟类工具的"防分心"能力天然受限——手机本身就是最大的干扰源。把手表变成专注守护者，恰好发挥了 Vela 设备**贴身佩戴、传感器丰富、震动直达**的独特优势，是"只有手表能做好"的场景。

## 四、运行方式

**环境要求**：Node.js ≥ 16（实测 22 可用）；推荐使用 **AIoT IDE**（VS Code 内核 + vela.aiot-core 扩展）。

```bash
cd quickapp/com.application.watch.demo
npm install

# 开发模式：自动编译并打开 Vela 模拟器
npm run start

# 发布构建
npm run release
```

**页面流程**：`index` 选择模式 → `timer` 开始专注（传感器监测中，分心即震动）→ 结束后进入 `detail` 查看分心台账 → `report` 查看 AI 分析报告。

**模拟器注意**：模拟器通常没有真实加速度计，应用会自动降级为模拟传感器数据（界面显示 `[模拟传感器]` 标签），全部功能流程仍可完整演示；真机部署后即为真实传感器数据。

## 五、AI Coding 使用说明

本作品全程借助 AI 编程助手（WorkBuddy AI Agent）协作开发，覆盖以下环节：

- **需求拆解与方案设计**：从"手表防分心"一句话需求拆解为 4 页面应用架构与数据流（`globalData` 传递会话数据）
- **编码**：Vela 快应用 `.ux` 页面、`@system.sensor` / `@system.vibrator` API 接入、分心检测状态机（阈值判断 + 冷却期）均由 AI 生成、人工确认
- **调试**：传感器回调无数据、list-item 渲染异常等问题的定位与修复
- **文档**：本 README 与作品介绍文档的撰写

AI 显著缩短了 Vela 快应用 API 的学习曲线，让没有快应用开发经验的队伍在一周内完成从 0 到可提交的作品。**完整原始对话日志（jsonl 格式，含工具调用记录）见 `logs/` 目录，未做任何删改。**
